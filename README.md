# ⚡ Free Serverless Crypto Funding Rate Scanner

A 100% free, lightweight Python script scanning perpetual funding rates for core crypto assets (**BTC, ETH, SOL, XRP, ADA**) on Kraken. Runs **24/7 for $0/mo** via GitHub Actions with instant Telegram notifications.

---

## 🛠️ Quick Setup (5 Minutes)

1. **Fork this repository** to your GitHub account.
2. **Create a Telegram Bot:**
   - Create a bot via [@BotFather](https://t.me/BotFather) and copy your `TELEGRAM_BOT_TOKEN`.
   - Get your `TELEGRAM_CHAT_ID` via [@userinfobot](https://t.me/userinfobot).
3. **Configure GitHub Secrets:**
   - Go to `Settings` -> `Secrets and variables` -> `Actions` in your forked repo.
   - Add `TELEGRAM_BOT_TOKEN` and `TELEGRAM_CHAT_ID`.
4. **Enable Workflow:**
   - Go to the `Actions` tab and enable/run the workflow.
